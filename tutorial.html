Marelli Media Log Analyzer

A quick guide to importing, editing, filtering and reading Android logcat output.

1. Load a log

Open a file from the sidebar, drag one onto the drop target, or paste logs into Raw Log Editor. Pasted text is parsed live after you pause typing. File imports are streamed to protect memory with large logs.

2. Read the result table

The first PID in PID/TID determines its color; the TID remains gray. Date and time have separate colors. Drag horizontally when a long message extends beyond the available width.

3. Filter with search tags

Type a regex in Search regex tags and press + or Enter. Every tag is independently toggled and removable. Enabled tags are combined: a line must match at least one active tag. Use Hide matching lines to invert the result. Level filtering can be combined with tags.

4. Highlight without filtering

Add regexes in Highlight. Matches are colored in the table, but no rows are removed.

5. Navigate between views

Use Filtered results for the active filter view and All retained lines for everything currently loaded. Click any table row to select the matching raw line in Raw Log Editor.

6. Resize your workspace

Drag the thin divider beside the sidebar to change its width. Drag the divider between Raw Log Editor and the results table to prioritize either pane. Use the hamburger icon to collapse the sidebar.

7. Saved logs and repository map

Expand Saved log library in the sidebar to reopen or delete browser-local imports. Reopening a saved log loads its content into Raw Log Editor. Load a repository class-name JSON map to use it in your own searches.
