Logalizer

A local-first Android logcat and DLT log analyzer. No server, no build step, no network required after download.

About

Logalizer helps you import, filter, highlight, and navigate large automotive and Android logs in the browser. Files are streamed during import to stay responsive, and the results table is virtualized so only visible rows are rendered.

  • Supports logcat and DLT formats with auto-detection
  • Regex search tags, level filters, and independent highlight patterns
  • Repository class map with per-component row coloring
  • Raw log editor with row sync and browser-local saved logs

What's included

The archive contains the full static source: HTML, CSS, and ES modules. Open index.html in Chrome or Edge to run it.

  • index.html — main analyzer
  • js/ — parser, filter engine, virtual grid, and app logic
  • styles/ — UI stylesheets
  • README.md — setup and operating notes
